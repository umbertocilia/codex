# codex

This repository contains a minimal Phaser.js starter project to kick off a browser-based game.

## Getting Started

Open `phaser-app/index.html` in a modern browser. The page loads Phaser via a CDN and starts a simple scene displaying the text "Hello Phaser!" on a dark background. Check the browser console for a startup message.

Use this template as a foundation for your own Phaser-based games by extending `main.js` with your game logic and assets.
