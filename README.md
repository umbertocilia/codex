# codex

This repository contains a small Phaser.js platformer inspired by classic Super Mario games.

## Getting Started

Open `phaser-app/index.html` in a modern browser. The page loads Phaser via a CDN and runs a tiny side-scrolling level. Use the arrow keys to move the character, collect coins and jump on platforms.

Feel free to extend `main.js` with additional levels, graphics or gameplay mechanics.
